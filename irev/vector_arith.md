# 昇腾 910B (dav-c220-vec) AIV 向量算术指令编码逆向报告

日期:2026-10-10。方法:受控变体 + 字节 diff(工具链:bisheng + ld.lld + llvm-objcopy,实验代码与脚本在 `/tmp/irev_vadd/`:`k.cpp`/`kprobe.cpp`/`kpad.cpp`、`build*.sh`、`bdiff.py`/`ddiff.py`,所有变体 `.text` 均已保留)。

实验基线:单核 kernel,TBuf 分配 3 个 8KB UB 缓冲(x@0x80, y@0x2080, d@0x4080),编译期常量 count=64,一次二元/一元/标量向量运算 + DataCopy 写出。

## 1. 指令长度

以连续 N 条相同运算(不同 UB 偏移)的 .text 长度阶梯测量(稳态,N≥2):

| 运算形态 | 每条增量 | 组成 |
|---|---|---|
| 二元 (Add/Sub/Mul/Max/Min) | **20 字节 = 5×32bit** | 3 条地址设置字(0x07 类)+ 8B 向量指令(寻址模式字 + 操作码字) |
| 一元 (Exp/Sqrt/Abs/Ln/Rsqrt/Relu/Reciprocal) | **16 字节 = 4×32bit** | 2 条地址设置字 + 8B 向量指令 |
| 标量 (Adds/Muls/Maxs) | **16 字节 = 4×32bit** | 2 条地址设置字 + 8B 向量指令(标量立即数在循环外只装一次) |

- N=1 时向量指令可见块只有 8B:`80 00 40 80 | <操作码字>`(地址设置被调度器打散到前面)。
- 每条运算的 20/16B 中,**向量指令本体 8B**,其余是 0x07 类的操作数地址设置指令(每操作数 4B)。稳态块示例(连续 Add f16,第 i 条):
  `XX 2X 04 07`(y 地址)`XX 0X 0c 07`(x 地址)`XX 4X 0e 07`(d 地址)`00 04 e0 40`(寻址模式字)`14 61 4e 85`(操作码字)。
- 注意编译器会做软件流水/重排,块边界是对齐周期模式后确认的。

## 2. 指令类标记(字顶字节,byte3)

所有指令 4B 对齐、32bit 字、小端。顶字节 = 大类:

| 顶字节 | 类别 |
|---|---|
| 0x07 | 标量/地址单元指令(movi、count 设置、向量地址设置;`XX XX {04,0a,0c,0e,...} 07`) |
| 0x83 | 向量一元算术 |
| 0x85 / 0x87 / 0x89 | 向量二元算术(add/sub 家族 / max/min 家族 / mul) |
| 0x96 / 0x97 | 向量标量算术(maxs / adds、muls) |
| 0x40、0x04、0x02、0x0f、0x08… | 其他(同步、控制、DataCopy 相关,本次未深入) |

## 3. 操作码字(opcode word)字段映射

二元运算 N=1 基线块:`80 00 40 80 | b0 b1 b2 b3`。已定位字段:

| 字段 | 位置 | 取值 |
|---|---|---|
| 指令类/主 opcode | byte3 | 一元 0x83;Add/Sub 0x85;Max/Min 0x87;Mul 0x89;Adds/Muls 0x97;Maxs 0x96 |
| 加减/极性位 | byte0 bit0 | 二元:Add/Max=0,Sub/Min=1(0x14↔0x15) |
| 标量版 sub-op | byte0 bit0 | Adds=0x88,Muls=0x89 |
| dtype | byte2 bits[7:6] | s32=00,f16=01,s16=10,f32=11(=0x06/0x46/0x86/0xC6,低 6 位恒定 0b000110) |
| 一元 opcode | byte0 + byte1 | Exp=(0x88,0x00);Sqrt=(0x88,0x0C);Abs=(0x08,0x03);Rsqrt/Relu=(0x88,0x01);Ln/Reciprocal=(0x88,0x02) |

dtype 位验证:half↔float↔s16↔s32 的 Add 互 diff 仅动 byte2;一元 Abs f32/f16 diff 同样只动 byte2(0xC6↔0x46),位置一致。

注意:Ln 与 Reciprocal、Rsqrt 与 Relu(f32, N=1)生成了完全相同的 8B 编码——疑似编译器降到了同一硬件操作(或共享 microcode),未深究。

## 4. count / mask / repeat

- 编译期常量 count 以 **16-bit 元素数立即数** 出现在一条 0x07 类标量字 `XX XX 08 07` 中(count=64→`40 00 08 07`,32→`20 00`,128→`80 00`,300→`2C 01`)。
- dtype 改变(16↔32bit、count 不变)时向量指令除 dtype 位外无任何变化 → mask/repeat 不进算术指令编码,应来自该 count 寄存器 + dtype 硬件推导。

## 5. 标量立即数(Adds/Muls/Maxs)

**立即数不进向量指令本体**,由标量单元 movi 装入寄存器:
- f16:单条 `XX XX 0a 07`,低 16 位 = half 位型(2.0→`00 40`,3.0→`00 42`)。
- f32:两条 0x07 字 = 高 16 位 `XX XX 4b 07` + 低 16 位 `XX XX 0a 07`(2.0f→`00 40 4b 07` + `00 00 0a 07`;-2.0f→`00 c0 4b 07`;100000.0f=0x47C35000→`c3 47 4b 07` + `00 50 0a 07`)。
- 标量版向量指令(opcode word `88 02 c6 97` for Adds f32)引用该寄存器,变立即数只动 movi 字。

## 6. 寻址(部分未解)

- 向量指令第一字(寻址模式字):N=1 时为 `80 00 40 80`,稳态为 `00 04 e0 40`。**改变 buffer 大小/绝对地址时此字不变** → 不含绝对地址,是操作数寻址模式/地址寄存器选择描述。
- 绝对 UB 地址由 0x07 类地址设置字携带:低 16 位 = UB 字节地址(连续 Add 阶梯中 y 字 0x2080→0x2100→0x2180,x 字 0x0080→…,d 字 0x4080→…,步长 0x80 = 64 half,与偏移完全一致)。字后缀(byte2 低半字节)区分目标:0x4/0xc/0xe、0xa/0xc 等,疑似"写第 n 号向量地址寄存器"。
- 操作码字 byte0/byte1 的高位随寻址场景变化:N=1 Add `14 01`,地址变体(x 移位)变 `98 21`,y 移位变 `88 01`,稳态 `14 61`;一元 `88 00`→稳态 `88 50`;标量 `88 02`→稳态 `88 62`。推测是 dst/src0/src1 的地址寄存器编号/模式位。**具体位域布局未解出**(变体间寄存器分配策略不一致,pady128 与 pady256 编码完全相同,说明只依赖分配到的寄存器号而非绝对地址)。
- opcode 字 byte2 的 bits[3:1] 也随寻址模式变化(0x46→0x4a/0x4e),bits[5:4]=0b11 恒定,功能未知。

## 7. 统一格式总结(当前认知)

```
向量算术运算 = [0..3 条 0x07 类地址设置字, 每操作数 1 条(可被打散/复用)]
             + 8 字节向量指令 = [寻址模式字 4B][操作码字 4B]
操作码字: byte3 = 指令类(0x83/0x85/0x87/0x89/0x96/0x97)
          byte2[7:6] = dtype (s32/f16/s16/f32 = 00/01/10/11)
          byte0~byte1 低位 = sub-opcode(加减极性、标量版运算、一元运算种类)
          byte0~byte1 高位 + byte2 低位 = 操作数寻址/寄存器选择(未完全解出)
```

## 8. 未解/待办

1. 操作码字 byte0/byte1 中地址寄存器编号的确切位域(需要固定寄存器分配的正交实验,如强制操作数顺序互换)。
2. 寻址模式字 `80 00 40 80`(N=1)vs `00 04 e0 40`(稳态)的语义与位域。
3. 0x07 类字的完整字段表(movi 高/低半、count 设置、地址设置的 sub-op 编码规律;byte2 似乎是缓冲/张量 ID,随 TBuf 数量 +2 平移)。
4. mask/repeat 寄存器的设置路径(只观察到 count 立即数字)。
5. 二元运算 0x85/0x87/0x89 与标量版 0x97/0x96 之间、一元 0x83 的内部 opcode 编号规律(样本仍少)。
6. 其他类别(0x40/0x04/0x02/0x0f 顶字节:同步、DataCopy、分支)未系统分析;DataCopy 的 burst 长度字段已顺带确认(写出指令中 512 half→0x20、512 f32→0x40,单位 32B)。
